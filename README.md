# Oscar Redesign

Plain HTML, CSS and JavaScript — no build step, no dependencies.

## Structure

```
index.html        Page markup
css/styles.css    Styles (design tokens, base, layout)
js/main.js        Scripts
assets/           Images, icons, fonts
```

## Running

Open `index.html` in a browser, or serve the folder locally (e.g. the VS Code Live Server extension, or `npx serve .`).
